## 1. 입국

- TODO: 비자 정책 변경 잦음 — 출장 직전 재확인.
- **한국–브라질 직항 없음** — 지구 정반대편이라 어떤 노선이든 최소 1회 이상 경유. 총 이동 시간이 길어 중간 휴식 계획을 미리 짜 두는 편이 좋음. — 조영우 (ICLR 2026.04)
- **북미 경유 루트 (실제 이용)** — 인천 → 뉴욕(JFK) 직항으로 미국까지 간 뒤, 산티아고(SCL) 등을 경유해 리우(GIG) 입국. 뉴욕에서 하루 자거나 12시간 정도 길게 경유해 체력을 회복하고 움직임. 경유지 공항 호텔 대실은 [뉴욕 (New York)](../usa/new-york.md) 참고. — 조영우 (ICLR 2026.04)

## 2. 일반 문화

- **팁은 따로 줄 필요 없음** — 식당 등에서 명시적으로 요구되는 팁은 없었음 (청구서에 서비스료가 포함되는 구조). — 조영우 (ICLR 2026.04)
- **영어가 잘 안 통함 — 번역기 필수** — 영어를 하는 사람이 많지 않음. 번역 앱을 적극 활용할 것. 특히 Claude 같은 AI 앱의 음성 인식으로 대화하면 편함. — 조영우 (ICLR 2026.04)
- **카샤샤 (Cachaça)** — 사탕수수로 만드는 브라질 증류주로, 럼과는 다른 술. 보통 라임과 설탕을 넣어 칵테일(카이피리냐, Caipirinha)로 마심. 관광지에서 한 잔 사 먹어볼 만함. — 조영우 (ICLR 2026.04)
